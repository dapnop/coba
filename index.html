Materi: Algoritma dan Pseudocode

Pahami dulu konsepnya sebelum menjawab kuis di halaman berikutnya, ya.

1. Apa Itu Pseudocode?

Pseudocode adalah kode semu yang ditulis menggunakan bahasa manusia (bukan bahasa pemrograman yang sesungguhnya) untuk merancang alur logika sebuah program. Pseudocode membantu kita menyusun langkah-langkah penyelesaian masalah secara runtut, sebelum langkah-langkah itu diterjemahkan menjadi kode program yang bisa dijalankan komputer.

2. Fungsi Pseudocode dalam Pemrograman

  • Membantu programmer merancang logika program tanpa terbebani aturan sintaks bahasa pemrograman tertentu.
  • Memudahkan proses diskusi dan pengecekan alur program sebelum benar-benar ditulis dalam kode.
  • Mengurangi risiko kesalahan logika (bug) karena alur berpikir sudah diuji terlebih dahulu secara sederhana.

3. Contoh Pseudocode dalam Kehidupan Sehari-hari

Perhatikan contoh berikut. Logika ini seperti kebiasaan kita mengecek cuaca sebelum berangkat sekolah:

ALGORITMA CekCuaca
DEKLARASI:
    kondisiCuaca : Teks
DESKRIPSI:
    BACA kondisiCuaca
    JIKA kondisiCuaca == "Hujan" MAKA
        Ambil dan bawa payung
    SELAIN ITU
        Tidak perlu bawa payung
    AKHIR-JIKA

4. Dari Pseudocode ke Bahasa Pemrograman

Pseudocode

INPUT nilai
IF nilai >= 75 THEN
    PRINT "Tuntas"
ELSE
    PRINT "Remedial"
ENDIF

Python

nilai = int(input("Nilai: "))
if nilai >= 75:
    print("Tuntas")
else:
    print("Remedial")
